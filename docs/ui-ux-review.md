# 개인용 Todo Planner UI·UX 재검토

이 문서는 `main`의 React 화면 코드와 로그인된 Production 화면을 기준으로 작성했다. 개인이 매일 쓰는 흐름에서 자주 찾는 기능을 앞세우고, 기존 데이터와 기능은 유지하는 것을 우선한다.

## 현재 화면별 문제

- **오늘:** 완료율·남은 Todo·주간 완료율이 별도 카드로 반복되고, 카테고리별 진행 카드가 바로 아래 카테고리 Todo 목록과 정보를 중복한다. 어제 미완료가 없어도 가져오기 패널이 렌더링된다.
- **주간:** 7열은 `2xl`에서만 적용되어 1440px 데스크톱에서도 4열+3열로 나뉜다. 네 개 요약 카드가 공간을 많이 차지하고, Todo 제목 버튼은 동작하지 않으며 전달된 `onUpdate`도 사용하지 않는다. 삭제 버튼은 hover 때만 나타나 터치·키보드 접근이 어렵다.
- **월간:** 달력+선택 날짜 패널 구조와 모바일 overflow는 양호하다. 다만 날짜를 선택하는 `role="button"` 요소 안에 수행 상태 버튼이 중첩되어 접근성 트리에 button 안의 button으로 노출된다.
- **전체 Todo:** 검색·필터와 카테고리별 목록 구조가 이미 목적에 맞으며 새 기능이 필요하지 않다. 공통 Todo 편집과 카테고리 관리 회귀 여부만 확인하면 된다.
- **메모:** 고정/일반 구분과 Markdown 편집은 갖춰져 있지만 검색이 없고, 제목이나 본문으로 기존 수정 Modal을 열 수 없다. 아이콘 버튼만 수정 진입점이라 카드 탐색과 키보드 사용이 번거롭다.
- **회고:** 작성 폼이 항상 큰 면적을 차지한다. 카드 안의 인라인 수정은 section만 바꿀 수 있고 취소가 없으며, 로컬 편집 상태가 외부 갱신과 어긋날 수 있다.
- **모바일 내비게이션:** 7개 메뉴가 하단의 한정된 가로 스크롤 영역에 모두 유지되고 페이지 자체 overflow는 발생하지 않는다. 기능 삭제나 구조 변경은 필요하지 않다.

## 이번 PR에서 수정하는 항목

- 오늘의 세 통계를 하나의 “오늘 요약”으로 합치고 ProgressBar를 유지한다. 중복 카테고리 진행 영역은 제거하며, 어제 미완료 패널은 가져올 항목이 있을 때만 표시한다.
- 주간 요약을 한 영역으로 합치고, 데스크톱에서는 7일을 한 줄에 배치한다. 좁은 화면은 주간 보드 안에서만 스크롤하며 Todo 제목으로 기존 `TodoEditModal`을 연다.
- 메모에 제목·내용 클라이언트 검색을 추가하고, 카드의 제목/본문을 마우스와 키보드로 열 수 있게 한다.
- 회고 작성은 명시적인 버튼으로 열고 취소·저장 후 초기화를 제공한다. 수정은 날짜·유형·sections를 편집하는 큰 Modal로 이동한다.
- 월간 날짜 카드의 중첩 클릭 요소만 분리한다. 달력과 선택 날짜 패널 구조는 유지한다.
- 현재 Wrangler 문법을 확인한 최소 배포·Worker 롤백 Runbook을 추가한다.

## 이번 PR에서 수정하지 않는 항목

- 이미 제공되는 Todo 토글·추가·삭제·더보기, 카테고리 생성·수정·삭제·정렬, 주간 목표, Markdown 저장/미리보기, 메모 색상·고정 기능은 유지한다.
- 개인용 앱에 불필요한 협업, 자동 저장, WYSIWYG, 파일 첨부, 서버 검색, 외부 관측 서비스, 자동 롤백·알림·주기 health check는 추가하지 않는다.
- 별도 설계가 필요한 월간 전면 개편, 월간 목표 패널, 내비게이션 재구성, 데이터 모델·API·D1 migration 변경은 제외한다.
- 인증, 보안 헤더, Rate Limit, D1 binding과 Worker 배포 구조는 변경하지 않는다.

## 검증 기준

- **모바일:** 390px 수준에서 페이지 가로 overflow가 없고, 주간 스크롤은 보드 내부로 한정되며 검색/추가·취소 버튼이 자연스럽게 배치된다.
- **일반 데스크톱:** 1440px 수준에서 월요일부터 일요일까지 한 줄로 읽히고 요약 영역이 반복 카드보다 적은 높이를 사용한다.
- **키보드 접근:** 메모 카드와 Todo 수정 진입, 삭제·닫기 버튼에 명확한 접근 이름과 focus 상태가 있고 중첩 클릭 요소가 없다.
- **빈 상태:** Todo·메모·회고가 없거나 메모 검색 결과가 없을 때 다음 행동을 이해할 수 있는 문구가 보인다.
- **Todo가 많은 상태:** 주간 더보기/접기, 카테고리 목록, 전체 Todo 필터와 수정 기능이 유지되고 제목·버튼이 카드 밖으로 넘치지 않는다.
