# 프로젝트 칸반 개편 설계

2026-11-12 · [앱 전체 기능·UI/UX 검토](app-ux-review.md)의 프로젝트 상세안. 앞서 제안한 개요·기록 탭을 단일 칸반 화면으로 대체한다.

## 화면 구성

- **머리글** — 프로젝트 선택, 상태, 시작일, 완료 개수, `작업 추가`를 둔다. 프로젝트 정보 수정·보관은 머리글의 `⋯`에서 접근한다.
- **일정** — Task의 예정일과 마감일은 카드와 상세에서 확인하고, 일정 편집은 상세에서 연다. 앱 전체의 날짜 탐색은 캘린더가 맡는다.
- **보드** — `할 일 · 진행 중 · 차단됨 · 완료` 네 열을 유지한다. 완료 열은 접을 수 있고, 진행 중 열은 기존 WIP 설정이 있을 때 전체 진행 건수와 한도를 표시한다. 보드 위에서 Task를 검색한다. 일괄 편집을 위한 표는 전체 Todo에서 프로젝트 조건을 적용해 연다.
- **카드** — 제목을 먼저 읽고, 필요한 카드에서만 예정일·마감일·우선순위·마일스톤·차단 사유를 확인할 수 있게 한다. `⋯`는 항상 접근 가능하게 둔다. 드래그, 메뉴, 키보드 모두로 상태를 바꿀 수 있게 한다.
- **Task 상세** — 제목을 눌러 기존 편집 기능을 연다. 상태·날짜·하위 작업·의존성을 한곳에서 수정하고 닫으면 원래 카드로 돌아간다. 데스크톱에서 상세를 띄울 때 열 너비가 급격히 줄지 않도록 배치를 선택한다.

열에 은은한 면 차이를 주고 상태색은 열 머리와 필요한 카드 표시만 사용한다. 프로젝트 색은 이름 옆에 한 번 표시한다. 1280px에서 프로젝트 선택은 머리글에 두어 보드 너비를 확보하고, 데스크톱에서 공간이 부족하면 보드 안에서만 스크롤한다. 모바일은 기존 진입과 Task 조작을 회귀 확인한다.

## 카드 제거

| 메뉴 | 변경되는 내용 | 복구 |
| --- | --- | --- |
| 프로젝트에서 제외 | 프로젝트·마일스톤 연결을 해제한다. Task와 예정일·마감일은 보존한다. | 영향을 받은 연결만 되돌린다. |
| 휴지통으로 이동 | 같은 Task를 프로젝트·오늘·캘린더·전체 Todo의 활성 목록에서 제거한다. | 기존 휴지통 복구 경로를 사용한다. |

하위 작업이 있으면 제외 범위를 명시한다. 부모만 제외하면 남은 자식과의 부모 연결을 해제하고, 함께 제외할 경우 영향을 받는 항목 수를 표시한다. 연결 변경은 한 번에 반영한다. 되돌릴 때 최근 제목·날짜 수정은 보존하고, 이미 제거된 마일스톤이나 달라진 연결은 복구 결과에 표시한다. 삭제한 선행 작업 때문에 후행 작업을 자동 완료하지 않는다.

처리 중에는 같은 요청의 재실행을 막고, 실패하면 카드 위치와 선택 상태를 복원한다. 복구 가능한 동작은 같은 위치에서 `되돌리기`를 제공하고 키보드 포커스가 있는 동안 만료를 늦춘다. 보관된 프로젝트와 조회 중 사라진 항목의 동작도 확인한다.

## 기존 기능과 적용 순서

현재 초안의 `ProjectPage`는 마일스톤과 결정 기록을 별도 화면으로 제공하며, `ProjectKanban`의 목록에는 삭제 경로가 있지만 카드에는 완료·상세·드래그만 있다. 카드 휴지통 이동에는 공통 Todo 삭제·복원 경로를 재사용한다. 프로젝트 제외는 기존 일괄 PROJECT 변경이 부모와 남은 자식의 관계까지 정리하는지 확인한 뒤 연결 변경 범위를 결정한다.

개요·결정 기록·분석은 칸반 구성에서 뺀다. 기존 자료 링크는 프로젝트 메뉴에서 접근하고, 저장된 결정 기록과 관련 데이터는 보존한다. 기존 기록 열람이 필요한 경우 현재 데이터를 읽을 수 있는 경로를 확정한 뒤 기존 화면을 교체한다.

1. 카드 메뉴의 휴지통 이동과 되돌리기를 연결한다. 성공·실패·재시도와 다른 화면 반영을 확인한다.
2. 프로젝트 제외와 관계 복구를 추가한다. 부모만·자식만·함께 제외, 마일스톤 누락, 동시 편집을 확인한다.
3. 칸반 머리글과 보드 배치를 정리한다. 1280·1440·1920px, 라이트·다크, 키보드 조작, 모바일 기존 동작을 확인한다.

카드 액션·열 설정은 [GitHub Projects 보드](https://docs.github.com/en/issues/planning-and-tracking-with-projects/customizing-views-in-your-project/customizing-the-board-layout), 날짜와 Task 연결은 [Linear 마일스톤](https://linear.app/docs/project-milestones)을 참고했다.
