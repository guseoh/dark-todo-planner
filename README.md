# Dark Todo Planner

개인 작업과 프로젝트를 관리하는 앱입니다. Todo, 캘린더, 프로젝트, 메모를 웹과 Windows 데스크톱에서 사용할 수 있습니다.

- [웹 앱 열기](https://dark-todo-planner.guseoh.workers.dev/)
- 웹은 React와 Vite, 데스크톱 앱 **Tern**은 Tauri 2, 백엔드는 Cloudflare Workers·Hono·D1을 사용합니다.

## Tern 설치 · Windows 11 x64

**[Tern 0.1.2 설치 파일](https://github.com/guseoh/dark-todo-planner/releases/download/tern-v0.1.2/Tern_0.1.2_x64-setup.exe)**

설치 파일을 실행한 뒤 Tern에서 로그인합니다.

**설정 → 앱 및 연결 정보 → Tern 업데이트**에서 설치 버전과 업데이트를 확인할 수 있습니다. 자동 업데이트는 새 버전이 [GitHub Releases](https://github.com/guseoh/dark-todo-planner/releases)에 공개된 뒤 제공됩니다.
